Kaiwu Archify browser adapter

KaiwuArchify.renderArchitecture(spec, { theme, id }) renders local architecture JSON into a complete standalone HTML string. The browser performs schema checks, engineering-profile checks, layout validation, SVG rendering and native viewer composition. The adapter does not fetch input or submit diagram data.

Run the synthetic example · Hashes and provenance · MIT license

Load the versioned public library

Use the immutable version directory, not an unversioned alias. The manifest supplies the exact SRI value. Normal site publishing requires no package installation or build step.

<script
  src="https://kaiwu-ai.github.io/vendor/archify-browser/d8e4daf-v1/archify-browser.js"
  integrity="sha384-CyW7WBiU/O0yG7mh3IWTRr2p4Scg+adraHXebQbztfOxckkqNo2cStiDdJSk+DoC"
  crossorigin="anonymous"></script>

Render local JSON

The required theme is light or dark. The required id is a lowercase kebab-case string, starts with a letter and is at most 64 characters. Each call returns a Promise; rejected errors expose archifyDiagnostics with codes, subjects, evidence and supported fixes. Calls do not mutate their input or share layout/diagnostic state.

const spec = JSON.parse(document.querySelector('#architecture-data').textContent);
const id = 'local-diagram';
const html = await KaiwuArchify.renderArchitecture(spec, { theme: 'light', id });
const url = URL.createObjectURL(new Blob([html], { type: 'text/html' }));
const frame = document.querySelector('iframe');
frame.setAttribute('sandbox', 'allow-scripts allow-downloads');
frame.referrerPolicy = 'no-referrer';
frame.src = url;

window.addEventListener('message', (event) => {
  if (event.source !== frame.contentWindow) return;
  if (event.data?.type === 'archify:ready' && event.data.id === id) {
    // Native initialization, API checks and synchronous SVG layout completed.
  }
});

// Before hiding or replacing the viewer:
frame.contentWindow.postMessage({ type: 'archify:suspend', id }, '*');
// Revoke url when this viewer is removed or replaced, not before it loads.

Keep specification data in a local script[type="application/json"] element and escape <, > and & as JSON Unicode escapes when embedding it. Do not upload private specifications, generated viewers, screenshots or source evidence to this public repository.

Browser boundaries

ContractBehavior
Supported inputUpstream architecture schema version 1, including free/grid layout, boundaries, connections, cards, guided views, locales and authored quality/engineering profiles.
Rejected featuresmeta.output, meta.repository, component sources and brand; custom templates, SVG, arbitrary option fields, accessor objects and non-JSON values.
Limits256 KiB serialized UTF-8 JSON; 128 components, 256 connections, 64 boundaries, 32 cards, 32 views, 512 items per array, 8,192 characters per string, depth 24, 20,000 values and numeric magnitude 1,000,000. Upstream schema limits also apply.
Motion and themeStarts in Still without persisting the choice. The validated theme wins over storage, URL parameters and OS changes. Native theme and motion controls remain interactive. Reduced motion, visibility and print pause motion; suspension also clears guided previews and settles handoffs.
Ready signalSent only after the native-script-end sentinel, required API checks and synchronous SVG geometry/layout measurement across a task/microtask boundary. Readiness does not wait for animation frames, which browsers may suspend for offscreen iframes. A captured script error or unhandled rejection suppresses readiness. The zero-view controller is supported without assuming an isPlaying method.
Child isolationHash-authorized inline scripts; inline styles required by the native viewer. CSP denies connections, fonts, external images, frames, workers, forms, object content and base URL changes. Blob/data images and Blob media support local export. There is no eval, filesystem shim, telemetry or input fetch.

Use a current ES2022 browser. A scripts-only sandbox has an opaque origin: clipboard, share links, persistence and some export capabilities depend on browser permissions and may be unavailable. Treat ready as initialization evidence, not a guarantee that every optional browser export API exists. A frame with no measurable layout does not report ready. The parent must use a timeout, show errors, authenticate event.source and the matching id, and revoke its Blob URLs.

Regenerate the vendored bundle

The only upstream is the public tt-a1i/archify repository at d8e4daf2610d512821365f41b139d874b29efe81. The build reads only files listed in tools/archify-browser/upstream-lock.json and verifies every SHA-256 before transforming source. A changed dependency, extraction marker or Node boundary aborts the build.

git -c core.autocrlf=false clone https://github.com/tt-a1i/archify archify-upstream
git -C archify-upstream checkout d8e4daf2610d512821365f41b139d874b29efe81
# Point the build at the directory containing assets/, renderers/ and LICENSE.
# In upstream layouts where the skill is nested, this is archify-upstream/archify.
cd tools/archify-browser
npm ci
node build.mjs <absolute-public-archify-skill-directory>
cd ../..
node --test tests/*.test.mjs

Only regeneration uses development tooling: esbuild is pinned to 0.25.12, with its dependency lockfile committed. The build accepts an optional third argument naming an existing esbuild module file and still checks its exact version. No upstream examples or repository evidence enter the bundle. Update the version directory for a published runtime change and update consuming SRI values together.

Adaptation and verification

The checked transformation wraps the native architecture renderer body per invocation, removes CLI/file/environment boundaries, retains precompiled validators and ordered validation, and substitutes exact no-brand return values only after rejecting brand fields. Diagnostics retain rich geometry evidence. The native template and algorithms remain upstream code; browser-specific edits remove remote font links and add theme, initial Still, zero-view, CSP and lifecycle seams.

Node tests exercise rendering, isolation, rejection, escaping, diagnostics, actual script hashes, byte provenance, lifecycle messages and theme seams using synthetic data. Run all existing site tests before publication. Real-browser layout, export behavior and publication must be independently verified; Node's bridge harness does not replace browser validation.
